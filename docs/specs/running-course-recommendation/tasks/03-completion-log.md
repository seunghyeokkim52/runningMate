# 03 — 완주 표시 및 개인 로그 저장·조회 (고정 테스트 사용자, 인터림)

## Outcome

선택한 코스를 완주 표시하면 그 시점의 날짜와 선택한 코스의 거리가 기록으로 저장되고, 사용자는 저장된 기록 목록을 볼 수 있다.

인터림 가정: 실제 로그인/계정 시스템이 없는 동안 고정된 단일 테스트 사용자로 모든 기록을 저장한다. 이 인터림은 계정/로그인 인프라가 마련되는 별도 작업으로 대체된다. 그때까지 spec.md의 "로그인하지 않은 사용자는 접근할 수 없다" 수용 기준은 이 작업 지도에서 검증하지 않는다.

## Blockers

- 02 — 거리 입력 기반 순환 코스 후보 추천 및 선택. 완주를 표시할 대상인 선택된 코스가 먼저 있어야 한다.

## Acceptance criteria

- [x] 후보 코스를 선택한 사용자가 완주 조작을 하면, 그 시점의 날짜와 선택한 코스의 거리가 기록으로 저장된다.
- [x] 저장된 기록 목록을 볼 수 있다.

## Constraints

- 고정된 단일 테스트 사용자 아래에 모든 기록을 저장한다(위 인터림 가정). 실제 계정 구분·인증 방식은 이 작업 범위 밖이며, 별도 작업이 대체할 때까지 유지되는 임시 동작이다.
- 저장소는 서버 프로세스 메모리 내 저장(모듈 스코프 Map)이다. 별도 DB 없이 "저장·조회"라는 수용 기준을 만족하는 가장 단순한 방법으로 선택했다. 개발 서버가 재시작되면 기록이 사라진다 — 실제 계정/DB 인프라가 마련되면 교체될 인터림이다.

## Verification

- 완주 조작 후 기록 목록에 정확한 거리·날짜를 가진 새 항목이 나타나는지 확인하는 결정적 테스트.
